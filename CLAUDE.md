@AGENTS.md

Whenever a change is made in this repo (or in the companion `scratch-club-assets` repo) that adds,
removes, or alters an external service dependency, or that changes editor behavior away from
stock Scratch, update `DEPENDENCIES-AND-CHANGES.md` to reflect it. That file is written for a
non-technical project owner — plain language, no jargon, and explicit about what breaks (and how
badly) if a dependency goes down.
